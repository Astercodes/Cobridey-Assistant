# Cobridey editorial redesign

The new interface uses a deep plum navigation shell, warm paper surfaces, magenta briefing panel, teal and orange campaign creatives, locally bundled DM Sans and Manrope, and Georgia editorial accents. Line icons are inline SVG. Layouts adapt to mobile; reduced-motion preferences disable transitions. Existing approval, scheduling, export and brand knowledge workflows are retained.

The campaign photo is an AI-generated concept featuring fictional models, visibly labeled in the interface. It is not a customer photograph or testimonial.

## Asset provenance

- File: `public/assets/cobridey-editorial.webp` (optimized from the original generated PNG).
- Generated with the built-in Imagegen tool.
- Fonts: Google Fonts DM Sans and Manrope, bundled with their SIL Open Font License files in `public/assets/`.

## Verification

Desktop and 390px mobile browser layout checks, content editor and quick-action checks, and existing API regression suite. Hosted accounts and AI generation workflows remain unconnected; design changes do not claim to implement those capabilities.
